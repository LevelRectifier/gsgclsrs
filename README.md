# Junteng Liu - Personal Academic Homepage (LJT-Homepage)

This repository contains the source of the personal academic homepage of
[Junteng Liu](https://github.com/Vicent0205), built with the
[Academic Pages](https://github.com/academicpages/academicpages.github.io)
Jekyll template (itself derived from the Minimal Mistakes theme).

> Note: the intended home of this content is a repository named `LJT-Homepage`
> forked from `academicpages/academicpages.github.io`. GitHub rejected the
> fork / rename / create operations for this account ("At least one email
> address must be verified to do that"), so the site source is kept here until
> the account restriction is lifted. The `_config.yml` already points at the
> `LevelRectifier/LJT-Homepage` repository name.

## Layout of the personal content

| Path | Purpose |
| --- | --- |
| `_config.yml` | Site-wide configuration: name, bio, e-mail, GitHub, Google Scholar, X (Twitter) |
| `_pages/about.md` | Home / about page: biography, research interests, education, research experience, publications, awards, contact |
| `_pages/publications.html` | Publications sub-page (auto-generated from `_publications/`) |
| `_publications/*.md` | One Markdown file per publication |
| `_data/navigation.yml` | Header navigation |

All biographic information in this repository is taken from the personal record
provided to me; no other content has been invented.
